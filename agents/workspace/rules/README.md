# 工作区规则（rules/）

本目录给**用户自己**写额外护栏（加法）。  
产品共享护栏在仓库 **`agents/rules/`**，运行时**直接注入**，不会拷进这里。

注入合并：`agents/rules/` ∪ **本目录**；仅当你在本目录放了**同相对路径**文件时，才会盖住共享份。

## 怎么写

1. 新建 `*.md` / `*.mdc`（可子目录）——只写你要加的约束。
2. 短约束即可；长手册放 `skills/`。
3. 与 `AGENTS.md`：人格/习惯写 AGENTS；可复用硬护栏写这里。
4. 若要覆盖某条共享规则：在本目录建**同名**文件（例如 `reply-style.mdc`），不要改仓库 `agents/rules/`。

不要指望「种子会把共享 mdc 拷进来」——那样会冻住旧副本并挡住共享更新。
